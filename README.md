# farleyfamilydental.com (static site)

Same page addresses as the WordPress site, so Google rankings carry over. Works on GitHub Pages (like STG) or Firebase Hosting.

## Launch checklist
1. Old WordPress media is already copied into `wp-media/` (GitHub workflow "Fetch WordPress media").
2. Publish: GitHub Pages (repo under Elevate-Practices, `CNAME` included) or `firebase deploy` (uses `firebase.json`).
3. Point DNS for farleyfamilydental.com at the new host; wait for HTTPS.
4. Check: home, 3 service pages, /book (lands on the booking form), an old URL like /dental-services/root-canals/.
5. Submit `https://farleyfamilydental.com/sitemap.xml` in Google Search Console.
6. Update the Google Business Profile website and Book links if they changed.
7. **Cancel the practice's WordPress hosting in GoHighLevel** to stop paying for it (only after steps 3–4 pass).

## Clean booking link
`/book` forwards to the practice's booking form. On Firebase it is a real 301 (`firebase.json`); on GitHub Pages `book/index.html` forwards instantly. Change the destination in both places if the booking form changes.

## Editing
Pages are generated by `build_site.py` from the content captured off the old site. Rebuild with `python3 build_site.py site`.
